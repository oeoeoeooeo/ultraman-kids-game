# 🌟 超人力霸王 小英雄遊樂園

給小朋友玩的超人力霸王（Ultraman）互動遊戲，單一 HTML 檔，無需安裝，繁體中文介面。
專為 4～6 歲小朋友設計：大按鈕、語音朗讀題目、答錯不懲罰、兩兄弟可一起玩。

**目前版本：v1.8.2**

## 🎮 遊戲模式

| 模式 | 說明 |
|------|------|
| 🦸 猜猜我是誰 | 看配色圖形與三層提示，猜出是哪位超人力霸王（共 67 位，昭和到 2025 奧米加） |
| 🌈 猜型態 | 三種問法：這是哪個型態？這型態是誰的？借用了誰的力量？（24 位角色、101 種型態、34 種融合） |
| 🔦 猜變身道具 | 貝塔膠囊、超人力霸王之眼、閃光劍、昇華器、傑斯的牙刷…雙向出題（47 位角色、40 種道具，附常見別名） |
| ⚔️ 變身！怪獸決鬥 | 選超人 → 拿道具喊名字 → 變身 → 打倒怪獸（99 隻可戰、17 隻大魔王），能量滿了放必殺技，每次輪替不同招式（光線／斬擊／飛踢／劍技各有動畫），可換一隻怪獸 |
| 🃏 翻牌配對 | 把超人和他的變身道具配成一對 |
| 💥 猜必殺技 | 「斯派修姆光線」是誰的？傑洛會哪一招？（67 位角色、231 種必殺技） |
| 🦖 猜怪獸 | 看 Emoji 與提示，猜出是哪隻怪獸（106 隻，超異象之謎到 Blazar） |
| 📖 怪獸圖鑑 | 依怪獸／宇宙人／機器人／大魔王／好朋友分類瀏覽，可直接挑戰指定怪獸 |

## 👶👦 為兩兄弟設計

- **弟弟模式**：3 個選項、翻牌 4 對；**哥哥模式**：4 個選項、翻牌 6 對
- **語音朗讀**：用瀏覽器內建台灣中文語音唸出題目與選項（不識字也能玩），答對後會等鼓勵語唸完才進下一題；首頁可切換聲音
- **兩人合作決鬥**：哥哥 `A` 攻擊 `S` 防禦，弟弟 `L` 攻擊 `K` 防禦，`空白鍵` 發射光線
- 答錯只會「再試一次」，星星永久累積（存在瀏覽器 localStorage）

## 🚀 怎麼玩

直接用瀏覽器開啟 `index.html`，或使用線上版本：

- Firebase Hosting：https://ultraman-kids-game.web.app
- GitHub Pages：https://oeoeoeooeo.github.io/ultraman-kids-game/
支援電腦（滑鼠、鍵盤）、平板與手機（觸控），直立、橫向皆有最佳化排版。
語音功能建議使用 Chrome 或 Safari。

## 🛠 技術

- 純 HTML / CSS / JavaScript，零依賴、零外部資源
- 角色以 SVG 向量繪製（非官方圖像）：肌肉輪廓軀幹、漸細四肢與拳頭、發光杏仁眼、光影漸層；四種花紋家族（條紋／銀色胸甲／左右分色／細線條）加九種頭冠。怪獸同樣以 SVG 繪製：七種骨架（雙足恐龍、人型宇宙人、機器人、四足獸、飛鳥、觸手怪、蛇龍）搭配每隻怪獸的配色與特徵設定（角、背棘、頭冠、尾刺、翅膀、鉗子、天線、鑽頭、觸手數、頭數、發光）
- 音效由 Web Audio API 即時合成，語音使用 Web Speech API
- 響應式排版：Container Queries、`dvh`、safe-area，涵蓋 375px 手機到桌機
- 部署：Firebase Hosting 免費 Spark 方案，未綁定帳單；`predeploy` 只把 `index.html` 複製到 `dist/` 上傳
- 安全標頭：嚴格 CSP（`connect-src 'none'`，不對外連線）、`X-Frame-Options: DENY`、`nosniff`、`no-referrer`、HSTS

## 📚 角色資料來源

角色名稱以維基百科〈[超人力霸王列表](https://zh.wikipedia.org/zh-tw/超人力霸王列表)〉的台灣譯名為主，常見別名以括號標示（例如：傑洛（賽羅）、太郎（泰羅））。

型態名稱以維基百科各角色條目（如〈[超人力霸王Orb](https://zh.wikipedia.org/zh-tw/超人力霸王Orb)〉、〈[超人力霸王Z](https://zh.wikipedia.org/zh-tw/超人力霸王Z)〉）的「型態變化」章節台灣譬名為準；雅克、勝利、銀河等條目無型態章節者採台灣常見譬名。

變身道具名稱以維基百科〈[超人力霸王列表](https://zh.wikipedia.org/zh-tw/超人力霸王列表)〉的「變身道具」欄位為準，並參照各角色條目「變身器」章節；台灣配音常用的別名以「也叫」標示。

必殺技名稱以維基百科各角色條目的「必殺技」章節台灣譬名為準（如〈[初代超人力霸王](https://zh.wikipedia.org/zh-tw/初代超人力霸王)〉、〈[超人七號 (角色)](https://zh.wikipedia.org/zh-tw/超人七號_(角色))〉、〈[超人力霸王Z](https://zh.wikipedia.org/zh-tw/超人力霸王Z)〉）；條目無此章節者採台灣常見譬名。

怪獸名稱以維基百科〈[超人力霸王怪獸列表](https://zh.wikipedia.org/zh-tw/超人力霸王怪兽列表)〉台灣版為準（哥摩拉、紅王、積頓、安托拉、扎拉布星人、哥爾贊、艾雷王、泰蘭特、札格古、貝澤魯卜等）；該列表未收錄的新世代怪獸採台灣常見譬名。
